## What is Plugin WhatsApp

Send message the notification using WhatsApp. Allow used with workflow or send other types messages using endpoint.

### Architecture

![](https://miro.medium.com/v2/resize:fit:1400/1*lQRMJvxzOGh711wDABKV-g.png)

### Collections

Collections are essential because they define the structure of the data stored in tables within your database. For this example, I created two collections, as described below.
 
1.  **ProvideConfig**
    -   **API Key**: Meta's API Key to access the WhatsApp API
    -   **URL**: API URL
    -   **Cell Phone From**: WhatsApp Business phone number
        
2.  **MessageQueue**
    -   **Content**: Message content
    -   **Status**: Pending or Completed
